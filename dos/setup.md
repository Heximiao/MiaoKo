# 运行与排错

按 [快速开始](../README.md#快速开始) 安装。控制台和 OneBot 收发使用 `build/miaoko-duplex-v46.dll`，独立群发命令使用 `build/miaoko-group-text.dll`。更新 DLL 前，先退出正在使用它的 QQ 进程。

## QQ 版本与监听

只有一个已登录的 QQ 实例时，MiaoKo 会自动接入。可以先启动控制台再登录 QQ。多个实例在线时，在「QQ 实例」选择要监听的账号。

提示版本不兼容时，用 QQ 安装目录做检查：

```powershell
.\.conda\node.exe .\src\qq\inspect-build.mjs 'C:\path\to\QQ'
```

`known-build` 表示匹配。版本相同但指纹不同会显示 `fingerprint-mismatch`。反馈问题时附上 QQ 版本、检查结果和脱敏日志。

## 控制台

快速开始中的 `--bind 127.0.0.1` 将控制台限制在本机。若需调整监听地址或默认端口 `8765`，在「通用设置」保存后重启，并去掉对应的命令行覆盖参数。

在「快捷触发」标题右侧选择正在监听的发送账号。戳一戳支持填写私聊 QQ 号或群号与成员 QQ 号，可发送 1–10 次，间隔可设为 0.1–2 秒。

「QQ 表情包摘要」按账号自动保存，可混选好友和群聊。启用快速模式时，摘要会在下一次匹配的发送后清空。常规模式支持填写触发次数，留空表示不限。

「合并转发」可以搜索目标会话并添加图文节点。每个节点可设置卡片预览昵称并通过 QQ 号选择头像。

重置管理密码时，停止控制台，然后在交互式终端运行：

```powershell
.\.conda\node.exe .\bin\dashboard.mjs --bind 127.0.0.1 --reset-password
```

根据终端显示的初始化码重新设置密码。运行数据和连接配置保存在 `data/`。
